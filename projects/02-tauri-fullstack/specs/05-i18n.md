# 05 - Internacionalizacao

Arquivos obrigatorios:

- `app/public/locales/pt-BR.json`
- `app/public/locales/en.json`
- `plugins/<id>/locales/pt-BR.json`
- `plugins/<id>/locales/en.json`

Chaves sao pontuadas, por exemplo `auth.login.title`. Os dois idiomas devem
ter o mesmo conjunto de chaves e placeholders. O validador compara o conjunto
de chaves aninhadas e falha em chaves ausentes, extras ou tipos diferentes.

Nao usar fallback hardcoded em JSX. Para strings de API, use o
`I18nService` e a chave documentada, nunca texto livre.
