# Design system

Tokens compartilhados por web, desktop e mobile Tauri:

- `src/tokens.css` - cor, borda, raio e sombra.
- `src/components.css` - estilos base dos componentes.
- `src/components/Button.tsx` e `Card.tsx` - componentes React acessiveis.

Nao use hex, spacing arbitrario ou componentes de UI fora desta pasta no
cliente. Novos tokens devem ser documentados em `shared/DESIGN-TOKENS.md`.
